- 🚫 **别搞「互关 100%」**：粉丝多但没人看，等于没有

## 4️⃣ 让 Claude 每天自动发

**思路：一台小虚拟机 + Claude 写帖子 + X 官方接口定时发布。**

### 🛠️ 搭起来就四步

1. 🖥️ **买台最便宜的云服务器**，跑定时任务就够了
2. 🔑 **去 X 开发者平台申请 API**，拿到发帖权限（按 X 当前定价付费）
3. ✍️ **给 Claude 一份「发帖说明书」**：账号定位、上面那张选题表、语气、禁用词（包开、100%、不封号），每条都带网页链接
4. ⏰ **设好定时**：每天固定时间，Claude 写 → 程序通过官方 API 发出去

### 🧠 让它越发越好

- 📊 每天抓前一天的曝光、点赞、点击，喂回给 Claude
- 🔄 让它每周总结：哪类帖子好、哪个时间段好，自己调整下周计划
- 👀 前一周先「只写不发」，你看着顺眼了再放开自动发布

### 🐦 X 的红线（踩了会封号）

- ✅ 只用官方 API，主页挂「Automated」标签，简介写清谁在运营
- 🚫 不自动关注、不自动点赞、不主动 @ 陌生人、不群发私信
- 🚫 不用浏览器脚本模拟点击——X 写明会永久封号
- 🔒 API Key 只放服务器环境变量，别写进代码、别传 GitHub
